# Sorting Algorithm Visualizer

An interactive sorting visualization application built with
Python and Streamlit.

## Features

- Visualizes four sorting algorithms.
- Generates random arrays.
- Adjustable array size and animation speed.
- Displays time and space complexity.
- Tracks comparisons and swaps or writes.
- Shows the final sorted array.

## Algorithms

| Algorithm | Average Time | Space |
|-----------|--------------|-------|
| Bubble Sort | O(n²) | O(1) |
| Selection Sort | O(n²) | O(1) |
| Insertion Sort | O(n²) | O(1) |
| Merge Sort | O(n log n) | O(n) |
